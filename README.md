# Power Zone 🏋️

Power Zone é uma landing page institucional para uma academia fictícia, desenvolvida com foco em design moderno, experiência do usuário e organização de código para portfólio.

O objetivo do projeto é simular uma página real de academia, apresentando:
- Proposta de valor
- Diferenciais da marca
- Planos e preços
- Seções informativas
- Captação de leads via newsletter

---

## 📌 Funcionalidades

- Hero Section com chamada estratégica para conversão
- Seção "Sobre" explicando a proposta da academia
- Destaques e diferenciais do espaço
- Planos e valores organizados visualmente
- Área de inscrição (newsletter)
- Layout totalmente responsivo (mobile, tablet e desktop)
- Animações suaves para melhorar a experiência visual

---


## 🛠 Tecnologias Utilizadas

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- shadcn/ui

---

## ▶️ Como rodar o projeto

Clone o repositório:

```bash
git clone https://github.com/Guilherme0Medeiros/Power-Zone-Landing-page

Instale as dependências:

npm install

Execute o projeto:

npm run dev

Acesse em:

http://localhost:3000
```
